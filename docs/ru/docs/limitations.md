# Ограничения и статус

Версия 0.1.0, ранняя. Ниже что работает, где это проверялось и чего пока нет. Сроков мы не обещаем.

## Что работает

Покрыто модульными тестами:

- формат описания с проверкой и JSON Schema;
- библиотека правил: каждый файл правил проверяется парсером самого Prometheus, правило «запросы перестали поступать» — ещё и его движком;
- генерация правил, базовой панели графиков, маршрутов Alertmanager и заготовок инструкций;
- контроллер с условиями в статусе;
- обнаружение сервисов, проверка на истории и поиск вероятного источника;
- интерфейс: список систем, схема, правила с карточками на понятном языке, проверка на истории и свои правила, режим YAML, страницы инструкций, каналы, страница состояния;
- сохранение описания из интерфейса: ресурс в кластере, файл локально;
- настройка Telegram и почты из интерфейса, собственные шаблоны сообщений;
- наборы программ и вход.

Сценарии интерфейса от начала до конца прогоняют сопровождающие перед каждым выпуском.

## Где проверялось

Одноузловой кластер k3s с OpenTelemetry Demo:

- Helm-чарт ставится и работает;
- библиотека правил срабатывает на встроенных сценариях сбоев демо;
- оповещения доходят в Telegram;
- наборы программ работают, включая поиск установленных программ и второй Prometheus.

## Чего пока нет и известные ограничения

- Готовый образ и репозиторий чартов не опубликованы. Образ собирается из исходников.
- Один общий пользователь, без ролей и журнала действий по пользователям.
- Длительного прогона на ложные срабатывания ещё не было. Запланирован прогон 72 часа на реальной нагрузке.
- Нет удаления устаревших объектов. Объект, который система перестала создавать (например, её AlertmanagerConfig после удаления последнего получателя), остаётся до удаления самой системы. При удалении системы удаляются все её объекты.
- Почта проверена только на тестовом SMTP-сервере, не у реального почтового провайдера.
- Свой Prometheus — только с Prometheus Operator. Запись в HTTP API Prometheus и Grafana не реализована.
- Одна установка — один кластер. Несколько кластеров не поддерживаются.
- Интерфейс только на русском. Оповещения — на русском или английском.
- Панели графиков базовые. Оповещения пока не дополняются трассами и логами.
- Каналы и поиск установленных программ — только в кластере. При локальном запуске их не настроить.
